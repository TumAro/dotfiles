ZELLIJ KEYS   (q closes this)

 panes     Alt+s  side        Alt+d  below       Alt+x  close pane
           Alt+arrows / Alt+h j k l  move focus  Alt+f  float on/off
 tabs      Alt+t  new         Alt+c  close       Alt+[ / Alt+]  prev / next
 apps      Alt+m  todo (tdx)  Alt+y  yazi
 session   Alt+q  detach (keeps running)
 lock      Ctrl+g  lock / unlock zellij keys (use if a key does nothing)
 more      Ctrl+p  pane mode   Ctrl+n  resize   Ctrl+s  scroll/search
           Ctrl+o  session mode (d = detach)

 terminal  ws          start or resume this repo's workspace
           ws -n       start another session for this repo (repo-2, repo-3...)
           zellij      plain session named after the repo
