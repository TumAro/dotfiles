# dotfiles

i3 setup. run `./install.sh` to get going.

---

## what's included

- **i3** -> window manager
- **kitty** -> terminal
- **zsh** + zinit + starship -> shell
- **helix** -> editor
- **yazi** -> file manager
- **polybar** + rofi -> bar + launcher
- **vesktop** -> linux native discord app
- cli tools: ripgrep, eza, bat, zoxide, delta

---

## apps I use usually

- zen -> lightweight + opensource browser
- obsidian -> notes
- vesktop -> linux native desktop app
- OBS -> screen record stuff
